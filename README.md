# File Diff Tool (uniqo)

A simple Bash tool to find lines present in First file but not in second file.

## 📌 Features
- Removes duplicates
- Sorts input
- Outputs unique lines from file1

## 🚀 Usage

```bash
chmod +x bin/uniqo.sh
./bin/uniqo.sh file1.txt file2.txt
